# Control anual del modelo d=3 — Berlín 2023

La inferencia d=3 suma **11.738,062673 GWh** en las 8.740 horas con features completas. La Strombilanz oficial auditada informa **11.780,229000 GWh** de consumo final para Berlín. La diferencia es **−42,166327 GWh (−0,357941 %)**.

Este control se clasifica como **consistencia condicionada**, no como validación independiente: las shares sectoriales de Strombilanz se usaron como entradas estáticas del contrato y la inferencia no cubre 20 horas sin features climáticas completas. La diferencia entre consumo final y carga HV también impide interpretarla como error horario del MLP.
