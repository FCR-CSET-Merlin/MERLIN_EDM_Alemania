# Auditoría de fuentes — Berlín

Esta carpeta reúne una ficha por fuente utilizada en la reconstrucción alemana. Cada ficha debe conservar URL, responsable, fecha de acceso, versión/período, licencia, unidad, cobertura, perímetro, transformaciones, faltantes y SHA-256.

Estados permitidos: `candidata`, `en revisión`, `aceptada`, `contexto` y `rechazada`. Una fuente solo es `aceptada` después de verificar cobertura, perímetro, definición, licencia y relación con el comparador KPI. La oficialidad de una fuente no resuelve por sí sola la compatibilidad entre demanda de red, consumo final y límites administrativos.

La primera auditoría documentada es [Stromnetz Berlin Restlast SLP 2023](stromnetz_berlin_restlast_2023.md).
